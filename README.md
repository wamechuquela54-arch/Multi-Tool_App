# Multi Tool App

A simple Python CLI application with multiple features.

## Features
- Calculator
- Word Counter
- History System
- File Persistence (save/load)

## How to Run
Run the Python file in your terminal:
Make sure you have python in your machine
python multi_tool_app.py

## Notes
This project was built as part of learning Python fundamentals including:
- Functions
- Lists and dictionaries
- File handling
- User input
